Method MakeCommand
MakeCommand overrides its parents method. It uses a sequence of if statements to detect the given command, if it is not found, it passes the parameter to the base method that deals with it in a similar way.
Syntax
C#
    public override ICommand MakeCommand(string commandType)
Parameters
commandType
A string that, ideally, corresponds to a commmand in the command factory, that can then be made into an object.
Return Value
